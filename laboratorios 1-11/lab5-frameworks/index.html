Framework seleccionado: Bulma

Descripción

En este laboratorio se aplicó el framework Bulma para mejorar la apariencia visual de una pequeña aplicación utilizando sus clases predefinidas.

Mini aplicación

Pregunta: Describe Material Design

"Material Design es un sistema de diseño desarrollado por Google que define reglas visuales y de interacción para crear interfaces consistentes, intuitivas y modernas. Utiliza principios como jerarquía visual clara, uso de colores definidos, tipografía estructurada, animaciones con propósito y sensación de “profundidad” mediante sombras y elevación. Su objetivo es mejorar la experiencia del usuario manteniendo coherencia entre aplicaciones web y móviles.-ACERCA DE MATERIAL DESIGN"
