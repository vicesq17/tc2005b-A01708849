¿Diferencias y semejanzas entre Java y JavaScript?

Ambos usan sintaxis similar y permiten POO. Java es fuertemente tipado y se compila a bytecode (JVM). JavaScript es tipado dinámico y se ejecuta en navegador o Node.js.

5 métodos de arreglos

push(), pop(), shift(), slice(), splice().
