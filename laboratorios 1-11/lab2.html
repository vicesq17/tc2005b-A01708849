Laboratorio 3: CSS

Uso de Bulma y CSS externo

1) Como ingeniero de software ¿cuál es tu recomendación sobre el uso de !important en un CSS?

El uso de !important debe evitarse en la mayoría de los casos, ya que altera el comportamiento natural de la cascada y la especificidad en CSS. Cuando se utiliza de forma excesiva, dificulta el mantenimiento, la escalabilidad y la depuración del código, generando conflictos innecesarios entre reglas. Desde una perspectiva de ingeniería de software, es preferible estructurar correctamente los selectores y jerarquías para que los estilos se apliquen de forma coherente. El uso de !important debería reservarse únicamente para situaciones excepcionales donde no exista otra solución técnica viable y siempre debe estar documentado.


2) Si se pone una imagen de fondo en una página HTML, ¿por qué debe escogerse con cuidado?

Una imagen de fondo impacta directamente en la experiencia del usuario, tanto en términos de rendimiento como de accesibilidad. Archivos de gran tamaño incrementan el tiempo de carga del sitio, afectando métricas de desempeño y posicionamiento en buscadores. Además, una imagen con colores o contrastes inadecuados puede dificultar la lectura del contenido principal. También es importante considerar la adaptabilidad a distintos dispositivos y resoluciones para evitar distorsiones o recortes inesperados. Por estas razones, la selección debe contemplar optimización, contraste adecuado y comportamiento responsivo.


3) Como ingeniero de software, ¿cuál es tu recomendación al elegir las unidades de una propiedad de estilo entre %, px y pt?

La elección de unidades debe basarse en principios de diseño responsivo y portabilidad. Las unidades relativas como el porcentaje (%) permiten que los elementos se adapten dinámicamente al tamaño del contenedor o la ventana, favoreciendo la compatibilidad con dispositivos móviles. Los píxeles (px) ofrecen mayor precisión y control cuando se requieren medidas específicas, como bordes o separaciones exactas. Las unidades en puntos (pt) están orientadas principalmente a medios impresos y no son recomendables para entornos web modernos. En general, se priorizan unidades relativas para lograr flexibilidad y escalabilidad en la interfaz.


4) ¿Por qué el uso de una versión minimizada del CSS mejora el rendimiento del sitio?

Una versión minimizada del archivo CSS elimina espacios en blanco, comentarios y saltos de línea innecesarios, reduciendo significativamente el tamaño del archivo. Esto implica menos datos transferidos desde el servidor al navegador, lo que mejora el tiempo de carga, especialmente en conexiones lentas o dispositivos móviles. Además, al disminuir el peso del recurso, se optimiza el uso del ancho de banda y se mejora la eficiencia general del sitio. Desde una perspectiva de optimización, la minificación forma parte de las buenas prácticas para el despliegue en producción.
