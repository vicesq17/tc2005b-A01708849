Lab 7: Manejo de Ramas

Guía rápida de Git para mortales

¿Qué son las ramas?

Imagina que el código es un árbol. La rama main es el tronco (lo que ya funciona), y tú creas ramas pequeñas para experimentar sin romper nada.

Main / Master

Solo código perfecto que ya está en internet.

Develop

Donde todos juntamos nuestras piezas nuevas.

Mi rutina diaria en Git

  • Crear tu espacio: git checkout -b mi-nombre/mi-tarea
  • Guardar avances: git add . y luego git commit -m "Explica qué hice yo VictorFere"
  • Sincronizar: No olvides hacer git pull para ver qué hicieron tus compañeros.

Regla Voy a estar bien guey si escribo código directamente en main.
